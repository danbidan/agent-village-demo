# 🖐 손그림 — 여기 넣으면 코드 그림을 이긴다

`도구/픽셀찍기.py` 는 `assets/pixel/` 에 **같은 이름으로 다시 찍는다.** 손으로 그린
PNG 를 거기 두면 도구를 한 번 돌릴 때 날아간다. 그래서 이 폴더가 있다.

**같은 이름이 여기 있으면 화면이 이쪽을 쓴다.** 몇 장만 넣어도 **그것만** 바뀐다.

## 규격 (안 지키면 자리가 어긋난다)

| | |
|---|---|
| 동물 | `npc-<종>-앞.png` · `-옆.png` · `-뒤.png` — **32×40** |
| 바닥 타일 | `tile-<이름>.png` (흙·풀·물·나무, 변종은 `tile-흙1`·`tile-흙2`) — **32×32** |
| 장소 | `vil-shed` `vil-stall` `vil-plaza` `vil-waterside` `vil-tree` `vil-bonfire` |
| 소품 | `furn-<이름>.png` |

- **1m = 32px** · 탑다운 3/4 시점 · **배경 투명**
- 🔴 **발이 그림 맨 아래**에 와야 한다 — 코드가 발을 기준으로 그리고,
  **누르는 판정(`몸틀`)도 그림 크기를 그대로 쓴다.** 위아래 여백이 있으면
  보이는 곳과 눌리는 곳이 어긋난다.
- 정수 배율로만 확대하므로 **32의 배수**가 가장 깨끗하다.
- 종: `dog` `owl` `bat` `mole` `cat` `rabbit` `otter` `squirrel`

## 조용하게 쓰려면 (선택)

파일을 넣기만 해도 된다. 다만 목록이 없으면 화면이 **모든 이름을 한 번씩 찾아보므로**
없는 것마다 404 가 한 줄씩 남는다. 장수가 많아지면:

```sh
python3 도구/손그림목록.py      # 이 폴더를 훑어 목록.json 을 만든다
```

목록이 있으면 **거기 적힌 것만** 찾는다.
