# 떡잎마을 거둠제 — 데모

> 축제의 케이크가 사라졌다. 동물 여덟 마리를 취조하고, 장소를 살펴보고, 수첩에서 범인을 지목한다.

**▶ 플레이:** https://danbidan.github.io/agent-village-demo/

- **서버 없이 돈다.** 동물은 미리 구워 둔 대사로 답한다(실제 게임은 LLM 이 그 자리에서 답을 짓는다).
- 판마다 범인이 바뀐다. 오른쪽 아래 🎲 로 다른 사건.
- 동물마다 느끼는 감각(냄새·소리·야간시각·진동)이 달라서, **누가 무엇을 알 수 있는지가 코드로 정해진다.**
  그래서 "이 동물이 알 수 없는 것을 말했나" 를 LLM 심판 없이 잴 수 있다 — 이 게임이 평가 장치인 이유다.

이 저장소는 **빌드된 데모만** 담는다. 소스·검사·평가 도구는 별도 저장소에 있다.
